## Objectives and Motivations
The dataset [1] used in this project is composed of 20,000 board games scraped from the Board Game Geek website [2]. This dataset comes with 52 columns of information about the 20,000 board games. Notable columns include:

- name - name of the game 
- sortindex - rank of the game on bbg.com
- minage - minimum age requirement per the publishers
- average - user average rating from 1-10
